# Panduan Pengguna Simentor - Indeks Dokumentasi v1.5

## 📚 Pendahuluan
Selamat datang di dokumentasi komprehensif Simentor. Panduan ini telah dipecah menjadi file khusus modul untuk membantu Anda menemukan informasi dengan lebih efisien.

### Panduan Modul
- [**Login & Akses**](login.md) - Cara mengakses sistem dan mengatasi masalah login.
- [**Profil Pengguna**](profil.md) - Mengelola data pribadi, kata sandi, dan pengaturan.
- [**Umum**](umum.md) - Data master, manajemen Pegawai, Surat (Dokumen), dan RKK DIPA (Anggaran).
- [**SKP (Kinerja)**](skp.md) - Perencanaan kinerja, pelacakan, dan metrik.
- [**Kegiatan**](kegiatan.md) - Katalog kegiatan, penugasan, dan evaluasi.
- [**Kontraktual**](kontraktual.md) - Manajemen SPK dan BAST.
- [**IPDS (Dukungan TI)**](ipds.md) - Tiket TI dan manajemen Aset.
- [**Bank Data**](bank-data.md) - Penyimpanan data mentah dan pengarsipan.
- [**Admin**](admin.md) - Akun pengguna, peran, dan konfigurasi metadata.

## 🎯 Legenda Panduan Visual

### Identifikasi Elemen Antarmuka
```
📋 = Formulir atau Dokumen
🔍 = Bidang Pencarian atau Filter
🖱️ = Diperlukan Tindakan Klik
⌨️ = Pintasan Keyboard
📊 = Tampilan Data/Tabel
🔄 = Proses/Alur Kerja
⚠️ = Area Peringatan/Kesalahan
✅ = Sukses/Selesai
❌ = Kesalahan/Gagal
🔐 = Keamanan/Izin
```

### Referensi Warna Status
```
🟢 HIJAU  = Sukses / Aktif / Disetujui
🟡 KUNING = Peringatan / Tertunda / Draft
🔴 MERAH  = Kesalahan / Ditolak / Kritis
🔵 BIRU   = Informasi / Netral / Memproses
⚫ ABU    = Nonaktif / Dinonaktifkan / Diarsipkan
```
