# Peta Referensi Antarmuka Pengguna Simentor v1.5

Dokumen ini berfungsi sebagai indeks utama untuk sistem dokumentasi Simentor. Dokumentasi telah dimodularisasi menjadi file terpisah berdasarkan area fungsional dan kebutuhan pengguna.

## 📚 Indeks Dokumentasi Utama

| Modul | File Dokumentasi | Cakupan |
|---|---|---|
| **Panduan Memulai** | [getting-started.md](getting-started.md) | Legenda visual, panduan navigasi, dan glosarium. |
| **Alur Kerja Utama** | [alur-kerja.md](alur-kerja.md) | **PENTING:** Skenario penggunaan aplikasi dari awal hingga akhir. |
| **Panduan Peran** | [panduan-peran.md](panduan-peran.md) | Tugas dan tanggung jawab berdasarkan peran pengguna. |
| **Troubleshooting** | [troubleshoots.md](troubleshoots.md) | Pemulihan kesalahan umum dan optimalisasi kinerja. |

## 🛠️ Detail Per Modul

| Modul | File Dokumentasi | Cakupan |
|---|---|---|
| **Autentikasi** | [login.md](login.md) | Proses login, persyaratan browser, dan masalah akses. |
| **Akun Pengguna** | [profil.md](profil.md) | Manajemen profil, ganti kata sandi, dan preferensi. |
| **Umum** | [umum.md](umum.md) | Data master pegawai, Surat Tugas/Keputusan, dan RKK DIPA. |
| **SKP** | [skp.md](skp.md) | Metrik kinerja, pelacakan progres, dan target. |
| **Kegiatan** | [kegiatan.md](kegiatan.md) | Katalog kegiatan, penugasan, evaluasi, dan pemantauan. |
| **Kontraktual** | [kontraktual.md](kontraktual.md) | Manajemen kontrak SPK & BAST dan pemantauan progres. |
| **IPDS** | [ipds.md](ipds.md) | Tiket bantuan TI dan manajemen aset TI. |
| **Bank Data** | [bank-data.md](bank-data.md) | Penyimpanan data mentah dan sistem pengarsipan. |
| **Admin** | [admin.md](admin.md) | Manajemen pengguna, definisi peran, dan metadata sistem. |

## 🛠️ Catatan Pemeliharaan
Saat memperbarui dokumentasi:
1. Identifikasi modul spesifik yang terpengaruh oleh perubahan.
2. Edit file `.md` yang sesuai di direktori `users-guides/`.
3. Perbarui nomor versi di `getting-started.md` jika ada perubahan signifikan.
